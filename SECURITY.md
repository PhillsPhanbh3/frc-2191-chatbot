# Security Policy

## Development Status

The FRC 2191 Chat Bot is currently in active development.  
Because this project is being built and tested alongside the FRC season, development and security hardening will continue over several months and may not be considered fully complete until before FRC Team 2191's first official competition event.

As the project evolves, security improvements, bug fixes, and additional protections will continue to be added.

---

## Reporting a Vulnerability

If you discover a security vulnerability, exploit, or other major issue, please report it responsibly.

When submitting a report, please include:
- A description of the issue
- Steps to reproduce the vulnerability
- Potential impact
- Screenshots or logs if available

Please do not publicly disclose vulnerabilities until they have been reviewed and addressed.

## Private security vulnerability reporting has been enabled on this repository!

---

## Vulnerability Handling

All reported security vulnerabilities will be acknowledged if they are within our control to fix.

Some issues may originate from third-party services, APIs, libraries, hosting providers, or platforms outside of our control. If this occurs:
- We will inform users that the issue is external
- We will monitor the situation
- We may need to wait for an official fix or patch from the affected provider

---

## Response Times During FRC Season

During the FRC competition season, response times may be delayed.

If a vulnerability or major issue is reported between Friday and Monday while FRC Team 2191 is actively competing, responses may not occur until Tuesday due to travel, competition schedules, and team operations.

Critical vulnerabilities may still be addressed sooner if possible.

---

## Supported Versions

At this time, only the latest development version of the FRC 2191 Chat Bot is supported.

Older builds, archived versions, or experimental branches may not receive security updates or patches.

---

## Security Best Practices

Users hosting or testing the bot should:
- Keep dependencies updated
- Protect bot tokens and API keys
- Avoid sharing sensitive configuration files
- Restrict bot permissions where possible
- Monitor logs for suspicious activity

---

Thank you for helping improve the security and stability of the FRC 2191 Chat Bot.
